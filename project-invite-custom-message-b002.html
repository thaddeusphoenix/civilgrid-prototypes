Project Invite — Custom Message
Purpose

Today's "Invite Team Members" dialog has no way to add a personal note — this tests where a custom message should live and whether it applies to the whole invite batch or to each recipient individually.

What to notice
  • The dialog chrome (search input, role select, About Roles) is the real "Invite Team Members" flow — only the message field is new
  • Use the toggle in the bar above to compare the two placements
  • "Batch message" — one message, sent to everyone in this invite
  • "Per-recipient note" — an optional note per staged email, added inline
Build history
  • b002 — fixed missing doctype/html/head/body wrapper
  • b001 — initial build
If we build this — Linear issues
API / data model

  • Add optional per-recipient note field to member invite records

Email delivery
  • Render the personal message block in the invite email template
  • Add a character limit and basic spam/profanity guard before send
  • Confirm message renders in plain-text email clients, not just HTML
Invite dialog UI
  • Add message textarea below staged invites (batch layout)
  • Add per-recipient "Add a note" expand/collapse control
  • Keep typed message if the dialog is closed and reopened before sending
Decisions & spikes
  • Batch vs. per-recipient message — which reads better at scale? (this prototype)
  • Should the message field extend to the bulk multi-project invite flow, or stay single-project only? (open, no Linear project yet)
  • Character limit and moderation approach for free-text invite messages (eng/security)
